# Koka

An [Exercism](https://exercism.org)-format track for [Koka](https://koka-lang.github.io), a functional language
with effect types and handlers, compiled to C with Perceus reference counting.

The track follows Exercism's [track layout](https://exercism.org/docs/building/tracks) and passes `configlet lint`.
Tests use the track-local harness in `lib/test.kk`, so an exercise needs nothing but the `koka` compiler and a C compiler.
