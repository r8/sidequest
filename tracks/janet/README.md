# Janet

An [Exercism](https://exercism.org)-format track for [Janet](https://janet-lang.org), a functional and imperative
language with a small bytecode VM, PEGs, fibers and a Lisp syntax.

The track follows Exercism's [track layout](https://exercism.org/docs/building/tracks) and passes `configlet lint`.
Tests use the track-local harness in `lib/test.janet`, so an exercise needs nothing but the `janet` binary.
