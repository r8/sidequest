# About

[Janet](https://janet-lang.org) is a functional and imperative programming language with a Lisp syntax.
It compiles to bytecode for a small, embeddable VM and ships as a single binary with no dependencies.

Janet has immutable tuples, structs and strings alongside their mutable counterparts (arrays, tables and buffers),
first-class functions and macros, fibers for coroutines and error handling, and Parsing Expression Grammars
(PEGs) built into the core library as the idiomatic way to parse text.
