# Help

To get help with Janet:

- read the [Janet documentation](https://janet-lang.org/docs/index.html) and the [API reference](https://janet-lang.org/api/index.html);
- try expressions in the REPL by running `janet` with no arguments; `(doc <symbol>)` prints a function's docstring;
- compare your solution with the example using `npx quest compare <track>/<slug>` once it passes.
