# Hints

## General

- [Mapping modifiers](https://mlochbaum.github.io/BQN/doc/map.html) explains table `⌜` (and each `¨`).
- [Array dimensions](https://mlochbaum.github.io/BQN/doc/shape.html) explains the shape of the result.

## 1. Price every base with every tint

- Table makes a function that applies its operand to every pair; which operand do you need?

## 2. Price every tin size

- The same idea with a different operand.

## 3. Name every mix

- Write the joining of one shade and one colour as a block, and use the block as the operand of table.

## 4. Match the orders to the shelf

- A string is a list of characters, so table pairs every character with every character.
