# Hints

## General

- [Blocks](https://mlochbaum.github.io/BQN/doc/block.html) describes modifier blocks and the operand names
  `𝔽 𝔾 𝕗 𝕘`.
- [Functional programming](https://mlochbaum.github.io/BQN/doc/functional.html) shows functions as values.
- [Syntactic role](https://mlochbaum.github.io/BQN/doc/context.html) explains how spelling sets a role.

## 1. Run an attachment twice

- In a 1-modifier block, `𝔽` is the operand used as a function.

## 2. Run one attachment, then another

- Mentioning `𝔾` makes a block a 2-modifier.
- Which of the two is applied to `𝕩` first?

## 3. Scale a recipe

- When the operand is a number, use it as a subject.

## 4. Try every attachment

- Inside a block, `𝕏` calls an argument as a function.
- Name the number first, so that an inner block can use it.

## 5. Set the measuring scoop

- A block can return a function, such as a bound one.
