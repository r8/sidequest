# Help

To get help with BQN:

- read the [tutorials](https://mlochbaum.github.io/BQN/tutorial/index.html) and the [primitive documentation](https://mlochbaum.github.io/BQN/doc/index.html);
- search [BQNcrate](https://mlochbaum.github.io/bqncrate/) for an idiom before writing a loop;
- run `bqn` for a REPL; `•Show` prints a value from inside a function;
- compare your solution with the example using `npx quest compare bqn/<slug>` once it passes.
