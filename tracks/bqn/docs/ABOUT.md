# About

[BQN](https://mlochbaum.github.io/BQN/) is an array programming language descended from APL. Every value is an
array, primitives such as `+´` (sum) or `⊐` (index of) apply to whole arrays at once, and short _tacit_
compositions like `+´÷≠` (the mean) say what a computation is rather than how to loop over it.

BQN keeps APL's power but cleans up its rough edges: first-class functions and modifiers, lexical scoping,
namespaces, a context-free grammar, and a small, consistent set of primitives with thorough documentation.
