# About

Forth is a stack-based, concatenative language from the early 1970s. A program is a sequence of _words_
that take their arguments from a data stack and leave their results on it; defining a new word with
`: name … ;` is the only abstraction mechanism, and it is enough to build the language itself.

Forth has almost no syntax and runs close to the machine, which makes it a favourite for embedded systems,
boot loaders and anyone who wants to think about computation one stack effect at a time.
