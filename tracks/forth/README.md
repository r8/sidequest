# Forth

An [Exercism](https://exercism.org)-format track for Forth, run with [gforth](https://gforth.org) 0.7.3.

Strings are not a native type in Forth, so this track curates numeric and stack-shaped exercises and
excludes string-heavy cases in `tests.toml`. Tests use the track-local harness in `lib/test.fs`.
