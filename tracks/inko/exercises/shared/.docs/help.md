# Help

To get help with Inko:

- read [the Inko manual](https://docs.inko-lang.org/manual/latest/) and the [standard library documentation](https://docs.inko-lang.org/std/latest/);
- `inko check` in the exercise directory type-checks your code without running the tests;
- binary operators have no precedence: `a + b * c` is `(a + b) * c`, so parenthesise arithmetic that mixes them;
- compare your solution with the example using `npx quest compare inko/<slug>` once it passes.
