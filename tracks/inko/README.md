# Inko

An [Exercism](https://exercism.org)-format track for [Inko](https://inko-lang.org), a language for concurrent
software with actors and single ownership instead of a garbage collector.

Exercises are Inko projects: the solution lives in `src/<slug>.inko` and the tests are ordinary `std.test`
tests in `test/test_<slug>.inko`, run with `inko test`. There is no extra harness.
